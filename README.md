Neon Coast Cover Studio turns any photo and a caption into GTA-style cover art: a multi-panel poster (six layouts from a four-panel Vice Grid to a nine-panel grid and tilted snapshots), a Vice City sunset or neon colour grade, bold Anton caption lettering with a glowing Pacifico subtitle, film grain and a badge ribbon — exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. It runs offline in a desktop browser from its own static files; photos never leave the machine.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 — drop a photo (or use a sample), pick a layout and grade, crop each panel, and export the PNG.
